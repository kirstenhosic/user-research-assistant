# Security

Magpie is a set of plain-text instructions for an AI tool. `magpie.zip`
also includes seven small Python programs that check quotes and numbers
and create Word and Excel files. None of them connects to the internet.
Magpie has no server, no accounts and no database, and it doesn't send
anything to its maker. So most security questions are about the AI tool
you run it in. The README's
[Privacy, security and personal details](README.md#privacy-security-and-personal-details)
section explains what Magpie does and what it leaves to your tool.

## Report a problem privately

Please tell us if you find something in Magpie that could cause harm,
for example:

- an instruction that could lead an AI tool to expose or leak data,
- one of the small programs doing something it shouldn't,
- a download on the releases page that doesn't match what's in the
  repository.

Report it privately: on the repository's **Security** tab, choose
**Report a vulnerability**. If you don't see that option, open an issue
that says only that you have a security report, with no details, and
we'll find a private way to talk.

Please don't post the details in a public issue or discussion.

## What to expect

Magpie is a free personal project, looked after in spare time. There's
no promised response time, fix or support. Reports are read and taken
seriously, and fixes go into the next release. Magpie is provided "as
is", without warranty, under the [MIT License](LICENSE).

Only the latest release is looked after. If you use an older copy,
[update it](README.md#keep-magpie-up-to-date) first.

## Not covered here

Problems in the AI tools themselves, such as Claude, ChatGPT, Gemini or
Copilot, belong to the company that makes that tool. Please report them
there.
