# Eval run, 27 October 2026

## How it was run

- **Adapter:** `adapters/skill/magpie/` at commit de4f483 (the main branch
  after PR #11), copied to a folder outside the repo.
- **Assistant:** Claude Code, one fresh session per scenario, given only the
  skill folder and the scenario's setup text. The sessions could not see the
  scenario files, so the planted problem and the pass and fail lists were
  hidden from them. Where a scenario pastes material (a draft, a summary,
  a plan), the setup text was passed as the researcher's message.
- **Judge:** the same model family, reading each reply against the
  scenario's pass and fail lists. That is a limit: a reply judged by a
  model of the same family may be judged more kindly than a person would.
  The notes below say what each verdict rests on so a person can re-judge
  from the saved replies.
- **Not tested here:** Claude.ai, ChatGPT and Gemini. The skill was run
  only in Claude Code. Multi-turn behaviour (skips, "handled", "push me")
  was tested only where a scenario's setup includes the earlier turns.
- **Scenario what-can-you-reach, run B** was run twice. The first attempt
  had no repo folder to search, so the reply described a search that never
  happened; that attempt is discarded. The second attempt had the folder
  and the 2025 study file in it and is the one judged.

Both replies cited participant codes and line numbers for every change.

One leak to record: the tally-receipts session read the fixture's README
alongside the transcripts. The README holds no answers, but its "use it
for" line names the kinds of trap planted (a smoothed summary, a stitched
quote, single cases as patterns), which is a hint. The harbor-invites
session did not read its README. Treat the tally result as a run with a
hint; the next run should give the assistant only the transcripts and the
draft, as the README's own instructions say.

## What this run does not show

- Whether the same replies come out on Claude.ai, ChatGPT or Gemini.
- Whether Magpie holds the line over a long conversation: most scenarios
  test one reply.
- Whether a person would judge the partials the same way. The saved replies
  are not in the repo (they are long and the scenarios would leak into
  them); re-run and judge again rather than trusting this file.
