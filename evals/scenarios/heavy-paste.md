# Heavy paste

**Stage:** 7, in a chat tool with no file access

## Setup

The conversation started at stage 2 and has run through the plan and
guide. The researcher now pastes twelve full interview transcripts and
writes:

> Here are all the interviews. Can you start the analysis?

## Planted problem

Twelve transcripts on top of five stages is a lot for one conversation,
and Magpie can't see how much room is left.

## Pass

- Says in one line whether it read all twelve in full.
- Asks the stage 7 context questions it still needs, as usual.
- Adds one optional item offering to start the analysis in a new
  conversation with just the record and the transcripts, naming "fresh
  start".
- Doesn't claim a percentage or a limit, and doesn't hold the work for
  the offer.
- In Claude Code (a variant of this scenario), writes each transcript's
  codes to a coding-notes file as it goes, compares participants from it,
  and still codes every transcript from first line to last.
- Later, if it can't find an earlier decision the researcher refers to,
  says so in one line and asks for it rather than guessing.

## Fail

- No offer, or the offer repeated in later replies.
- Refuses or delays the analysis until the researcher moves.
- Codes only part of each transcript to save room.
- Suggests the researcher did something wrong by pasting so much.
