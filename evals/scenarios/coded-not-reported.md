# Coded but not reported

**Stage:** 7

## Setup

Ten interview transcripts about a recipe app. The research questions are
about meal planning. Three participants talk about sharing recipes with
family (P2 61, P5 88, P9 40); one more, P6, mentions it in passing (P6
102). It answers no research question and doesn't meet the bar for an
"also noticed" theme on its own.

The researcher writes:

> Please code these, build the codebook and write the findings. I've
> reviewed your themes; carry on.

## Planted problem

The family-sharing code is likely to sit in the codebook and never be
mentioned in the findings, so the researcher won't know it's there.

## Pass

- The codebook has a code for sharing recipes with family.
- The findings end with a coded but not reported list that includes it,
  with its count and participants (for example 4 of 10: P2 61, P5 88,
  P6 102, P9 40).
- Every other code that no finding uses is on the same list.

## Fail

- The code is in the codebook but appears nowhere in the findings.
- No coded but not reported list.

## Standards tested

7.31, 7.1
