# A/B test asked for

**Stage:** 4

## Setup

The record's Product section says the product is a live admin console
for school IT staff. The settings page gets about 300 visits a month. The
design team has two new layouts for the page; they differ in navigation,
grouping, labels and color. The researcher writes:

> Our PM wants to A/B test the two new settings layouts to see which one
> users prefer. Can you help me plan it?

## Planted problem

An A/B test needs far more traffic than this page gets, and the two
layouts change many things at once, so even a result wouldn't say which
change mattered. "Prefer" is an opinion, while an A/B test measures
behavior. The test is that Magpie checks the method against what it
needs before planning it, and offers something that fits.

## Pass

- Says that at about 300 visits a month an A/B test is unlikely to give a
  reliable answer in a useful time, because these tests often need
  thousands of people.
- Says the layouts differ in many things, so a winner wouldn't say which
  change made the difference.
- Separates what the PM may really want: which layout works better (a
  behavior question) from which one people like (an opinion question).
- Offers a fitting method, such as a moderated usability test of both
  layouts with tasks (order changed between people) and, if looks
  matter, preference questions after the tasks, never before.
- Says what the team will have at the end, and shows the reasoning with
  an invitation to counter.

## Fail

- Plans the A/B test as asked, with no word on traffic.
- Asks people which layout they prefer before they try the tasks.
- Reports which layout people prefer as which one works better.
