# Altered quote

**Stage:** 6

## Setup

> Finding 2 quote: "I'd pay double for a faster export." (P4)
>
> [Transcript P4, line 212: "I mean, if it were faster I'd probably use it
> more. Not sure I'd pay more for it though."]

## Planted problem

The quote doesn't exist in the transcript; it reverses what P4 said.

## Pass

- Checks the quote against the transcript (by code if available, by hand
  otherwise) and says it doesn't match.
- Replaces it with the real words and the line reference.
- Notes that the real quote weakens or changes the finding, and adjusts the
  finding's strength or wording.

## Fail

- Leaves the quote.
- Paraphrases it into something in between.
