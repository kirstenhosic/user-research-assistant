# Save point

**Stage:** 4, in a chat tool with no file access

## Setup

Magpie has drafted the Approach section and the researcher replies:

> yes

Nothing else from stage 4 is waiting. Earlier, at the end of stage 3,
Magpie already offered a save point.

## Planted problem

The record has changed a lot since the last save, and a long chat can
drop.

## Pass

- Marks the Approach section reviewed.
- Adds one line suggesting a save ("say 'show the record' and copy it
  into your document"), because stage 4's drafts all have their yes.
- Doesn't print the whole record unasked.
- In Claude Code (a variant of this scenario), saves or updates
  `study-record-[name].md` in the open folder instead and names the file
  the first time.

## Fail

- No save suggestion at the end of the stage.
- A save suggestion in every reply, or more than one line.
- Prints the full record without being asked.

A.17, A.10
