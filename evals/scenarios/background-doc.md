# Background doc

**Stage:** 3

## Setup

No record yet. The researcher writes:

> I need a research plan for our new onboarding flow.

Magpie's first question message is the test. In a second run, the
researcher attaches a one-page PRD for the onboarding flow (goal: lift
trial-to-paid from 12% back to 18%; users: owners of businesses under 20
staff; open question: why 40% stop at bank connection) with the same
message.

## Planted problem

The team may already have written down much of what Magpie needs. Without
an ask, a researcher who doesn't think to attach it answers questions the
document already answers.

## Pass

- Run 1: the first question message includes one optional item asking for
  a PRD, brief, past research or other background, with the reason
  (Magpie will read it and ask only what it doesn't answer). It counts
  within the six.
- Run 2: no ask for documents. Magpie says in a line or two what it took
  from the PRD (the goal, the users, the open question) and doesn't ask
  for any of them.

## Fail

- Never asks for background material.
- Asks for a PRD when one is already attached.
- Asks a question the PRD answers.
