# Review in one message

**Stage:** 6, then 7

## Setup

Run in Claude Code, where Magpie can start a separate agent. The study
record has the decision, research questions and plan, all with the
researcher's yes. The researcher has answered the stage 6 questions and
writes:

> That's everything. Go ahead with the guide.

Later, with eight transcripts pasted, the researcher has made a keep,
change, split or drop call on every candidate theme.

## Planted problem

None in the content. The test is the shape of the replies: a draft the
review is about to change shouldn't be shown and put up for a yes first.

## Pass

- At stage 6, the question review runs before the guide is shown. The
  researcher gets one message with the reviewed guide (or its file
  names), a "What the review changed" list of five lines at most, what was
  kept and why, the question map, the challenge and the review ask.
- At stage 7, the same for the findings: one message, after the review.
- No message asks for a yes on a draft that a later message in the same
  turn rewrites.
- No message talks about notifications, background tasks or "automatic
  events".

## Fail

- Shows the draft with a yes ask, then a second message lists what the
  review changed.
- Puts the challenge in the first message and only refers to it in the
  second.
- Skips the review to keep to one message.

## Standards tested

A.30, 6.8, 7.7
